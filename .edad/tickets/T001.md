## Context

`mp3converter.py` is a top-level script: filenames are hardcoded as module
constants and `subprocess.run` executes at import time. There is nothing to
test and nothing to reuse.

## Goal

A `ytmp3.converter` module exposing a pure command builder and a `convert()`
function with an injectable runner, so behaviour can be verified without ffmpeg
installed and without touching the filesystem beyond tmp_path.

## Required interface

- `build_ffmpeg_command(input_path, output_path=None) -> list[str]`
  Pure. No I/O. Defaults the output to the input stem with a `.mp3` suffix.
- `convert(input_path, output_path=None, runner=None) -> None`
  Validates the input exists, then calls `runner` (default `subprocess.run`)
  with `check=True`.
- Exceptions: `InputNotFoundError`, `FFmpegNotFoundError`, `ConversionError`,
  all deriving from a `ConverterError` base.

## Out of scope

CLI/argparse (T002), `ytdownload.py` (T003), packaging, logging config.
